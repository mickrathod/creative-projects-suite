# ❄️ Winter Arc OS

> **The Ultimate Winter Arc Self-Mastery Operating System & Protocol Guide**

Winter Arc OS is a cyber-aesthetic habit tracker, calisthenics workout engine, skateboarding mastery log, and discipline dashboard built for relentless self-transformation.

---

## ✨ Key Features

- ⚡ **Mission Control HUD**: Daily streak counter, protocol completion percentage, habit toggles, and audio-visual feedback.
- 🏋️ **Workout & Calisthenics Engine**: Guided stages for push-ups, pull-ups, squats, pike push-ups, hollow body holds, and progressive overload.
- 🤸 **Handstand Laboratory**: 5-stage progressive handstand roadmap from wrist armor and hollow holds to wall walks and freestanding balance.
- 🛹 **Skate Log**: Trick tracking for stances, carves, kickturns, and ollies with technique tips.
- 📖 **Self-Reflection & Journaling**: Daily accountability logs, morning intentions, and evening debriefs.
- 📑 **Comprehensive Protocol PDF Guide**: Built-in 11MB offline protocol guide and generator.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Cyberpunk-inspired Neon Dark Mode CSS
- **Audio**: Web Audio API Sound Effects & Ambient Audio
- **Storage**: LocalStorage persistent state engine with backup/restore

## 📦 Setup & Development

```bash
# Clone the repository
git clone https://github.com/mickrathod/winter-arc-os.git

# Navigate into directory
cd winter-arc-os

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
