## 🚀 Detailed Product Highlights

### 1. 🏎️ ApexDrive 3D — Interactive Physics World & Developer Odyssey
* **Live App:** [https://mickrathod.github.io/apexdrive-3d/](https://mickrathod.github.io/apexdrive-3d/)
* **Technologies:** React 19, Three.js, Cannon-es 3D Physics, WebGL, Web Audio API, Vite
* **About:** An interactive 3D WebGL driving portfolio inspired by Bruno Simon. Features real-time vehicle suspension, tire friction, drift mechanics, collectible stars, interactive project monuments, dynamic camera modes (Chase Cam, Top-Down, Cinematic Orbit), day/night lighting cycles, procedural engine rev audio synthesis, and a live GPS radar HUD.

### 2. 🎧 PulseDeck Pro — Dual-Deck Performance DJ Station
* **Live App:** [https://mickrathod.github.io/pulsedeck-pro/](https://mickrathod.github.io/pulsedeck-pro/)
* **Technologies:** React 19, Web Audio API, HTML5 Canvas (60 FPS), Vite, Lucide Icons
* **About:** A hardware-grade browser DJ console modeled after Pioneer CDJ-3000 decks and DJM-900NXS2 mixers. Delivers real-time vinyl scratch physics on touch-sensitive platters, procedural dance track generators, 3-band isolator EQs with kill toggles, bipolar color sound filters, crossfader curve selection, an 8-pad performance sampler, and multi-band RGB dynamic waveforms.

### 3. 🎸 AuraStrings — Procedural Physical Guitar Synthesizer
* **Live App:** [https://mickrathod.github.io/aurastrings-guitar/](https://mickrathod.github.io/aurastrings-guitar/)
* **Technologies:** React 19, Web Audio API, Mathematical Karplus-Strong DSP, Vite
* **About:** A studio-grade virtual acoustic and electric guitar simulator powered by mathematical physical modeling. Plucks and strums are synthesized dynamically in real time by simulating string tension, damping, and body resonance. Includes interactive pick physics, upstroke/downstroke detection, chord voicing banks, and overdriven tube amplifier emulation.

### 4. ⚡ QuoteGenius SaaS — Reactive Estimation Engine & Inbound CRM
* **Live App:** [https://mickrathod.github.io/quotegenius-saas/](https://mickrathod.github.io/quotegenius-saas/)
* **Technologies:** React 19, Vite, Lucide Icons, Context API
* **About:** A high-converting pricing intelligence micro-SaaS for home service contractors and agencies. Features a visual formula builder, dynamic slider inputs, real-time quote calculation, embedded lead capture, inbound CRM pipeline with 1-click WhatsApp handoff, and a universal 1-line website embed script generator.

### 5. ⭐ ReviewBooster SaaS — Contactless Reputation Engine & Feedback Shield
* **Live App:** [https://mickrathod.github.io/reviewbooster-saas/](https://mickrathod.github.io/reviewbooster-saas/)
* **Technologies:** React 19, Vite, Canvas-Confetti, SVG Vector Graphics
* **About:** A dual-action reputation management SaaS for physical storefronts, restaurants, and clinics. Pairs a high-resolution QR counter stand designer with printable acrylic table tent styling (Ctrl+P ready). Utilizes an intelligent sentiment-routing funnel: 4–5 star ratings are routed to public Google Maps profiles, while 1–3 star ratings are intercepted to a private internal owner inbox.

### 6. 📅 BookingBolt SaaS — Zero-Friction Client Scheduling & Calendar CRM
* **Live App:** [https://mickrathod.github.io/bookingbolt-saas/](https://mickrathod.github.io/bookingbolt-saas/)
* **Technologies:** React 19, Vite, Lucide Icons
* **About:** An ultra-fast, embeddable appointment scheduling engine and calendar CRM for independent service professionals. Features a 30-second mobile booking funnel, dynamic weekly availability management, customizable service catalogs, appointment buffer times, deposit capture support, and instant WhatsApp confirmation messaging.

### 7. 📦 SubscribedOS — Subscription Box Operations & Recurring Revenue CRM
* **Live App:** [https://mickrathod.github.io/subscribedos-saas/](https://mickrathod.github.io/subscribedos-saas/)
* **Technologies:** React 19, Vite, Canvas-Confetti, Lucide Icons
* **About:** An end-to-end commerce management platform tailored for curated monthly subscription box businesses. Features a visual Box Theme Builder for planning monthly product assortments, itemized COGS profit margin calculations, subscriber fulfillment tracking, real-time MRR and churn analytics, and an interactive unboxing funnel simulator.

### 8. 🖼️ VisualProof — Interactive Before & After Transformation Gallery
* **Technologies:** React 19, CSS Hardware Clip-Path, Touch Drag Physics
* **About:** A high-conversion visual proof and media comparison suite designed for medspas, home remodelers, and auto detailers. Enables clients to drag an interactive comparison curtain revealing dramatic before-and-after work with 60 FPS touch tracking and integrated lead capture.

### 9. 📁 ArchivalIQ — Privacy-First Content-Aware Document & Financial Archive
* **Technologies:** Python, pypdf, Regex Heuristics, Watchdog
* **About:** A 100% offline, zero-API desktop document intelligence system for accountants, law firms, and contractors. Parses the internal text layer of PDFs to extract vendor names, document types (Invoices, Receipts, Statements, Contracts), transaction dates, and totals—standardizing filenames and categorizing files with atomic 1-click batch rollback protection.

### 10. 📍 AtlasLead AI — Autonomous High-Ticket B2B Local Intelligence Extractor
* **Technologies:** Python, Headless Playwright (Chromium), Stealth Heuristics
* **About:** An automated lead generation engine that scrapes geographic mapping networks for high-ticket local businesses. Extracts verified business names, telephone numbers, direct website URLs, star ratings, review velocity, and coordinates into structured CSV datasets for outbound sales prospecting.

### 11. 📸 InstaVelocity — Organic Direct-Message Sales Engine & Automator
* **Technologies:** Python, Playwright, Dynamic Spintax Engine
* **About:** An outbound social selling automation tool for agencies and SaaS founders. Uses persistent browser session authentication to protect account security. Features category-calibrated value pitches, nested Spintax variation to eliminate spam detection, variable human typing cadence, and dry-run safety simulation.

### 12. 💬 NexusWhatsApp CA — Targeted B2B WhatsApp Engagement Pipeline
* **Technologies:** Python, Chromium Automation, Spintax Engine
* **About:** A specialized WhatsApp messaging and client acquisition system calibrated for Chartered Accountants and tax consultants. Features consultative outreach sequences offering automated client document portals, filing status trackers, and practice management tools with built-in behavioral throttling.

### 13. 🎯 GroupRadar AI — Community Intelligence & Business Card OCR Extractor
* **Technologies:** Python, Windows Native OCR (`Windows.Media.Ocr`), Playwright
* **About:** A multi-modal contact extraction platform that scans WhatsApp group rosters and leverages hardware-accelerated local Windows OCR to extract CA names, firm designations, phone numbers, and cities from photographed visiting cards with complete privacy.

### 14. 💡 LuminaSmart — Dual-Condition Ambient Motion Lighting Controller
* **Technologies:** C/C++ (Arduino Embedded Firmware), ATmega328P, HC-SR501 PIR, CdS Photoresistor
* **About:** An embedded IoT lighting automation firmware implementing a dual-conditional logical AND gate (ambient darkness threshold + pyroelectric motion). Features software hysteresis filtering to prevent relay chattering, programmable re-triggerable timers, and sensor warm-up protection.

### 15. 🌱 FloraPulse — Autonomous Soil Moisture & Precision Irrigation Firmware
* **Technologies:** C/C++ (Arduino Embedded Firmware), ATmega328P, Soil Hygrometer, 5V Submersible Pump
* **About:** An embedded botanical preservation controller combining analog soil hygrometer sensing with pulsed hydration dynamics. Enforces a 1-hour absorption cooldown between irrigation pulses to prevent root hypoxia and water waste, accompanied by manual prime overrides.

## 💎 Design Philosophy & Core Principles

- **Zero Unnecessary Dependencies:** Pure, native implementations where possible (Web Audio API instead of heavy audio engines, CSS clip-path instead of bloated slider libraries).
- **Tactile & Responsive Feedback:** Real-time feedback in every application—from audio synthesis and physics simulation to instant price updates and visual confirmation animations.
- **Privacy & Security First:** Zero-cloud architectures for document processing and outreach tools, ensuring sensitive business data remains 100% local.
