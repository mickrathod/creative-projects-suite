# 🏍️ MotoRescue Bhavnagar

> **24/7 On-Demand Roadside Assistance & Garage Dispatch Platform for Bhavnagar, Gujarat.**

MotoRescue Bhavnagar connects stranded motorists, daily commuters, and vehicle owners across Bhavnagar directly with local certified mechanics, towing operators, and authorized service garages in real-time.

---

## ✨ Features

- 🚨 **One-Tap Emergency SOS**: Instant emergency assistance request with live GPS coordinates, vehicle category selection, and automated WhatsApp alert to dispatch.
- 📍 **Doorstep & Roadside Location Picker**: Precise locality selection covering Nilambaug, Ghogha Circle, Chitra GIDC, Kaliyabid, Rupani, Subhashnagar, and surrounding highway corridors (Ahmedabad Highway, Rajkot Highway, Talaja Road).
- 🛠️ **Transparent Cost Calculator**: Instant estimation for puncture repair, battery jumpstart, clutch cable replacement, towing, fuel delivery, and periodic maintenance.
- 📡 **Patrol Radar & Live Dispatch Board**: Live status tracking of nearest active mechanics and patrol units with ETA calculations.
- 🏢 **Multi-Role Portals**: Dedicated switchable interfaces for Customers, Garage Partners, and Central Dispatchers.
- 💬 **Instant WhatsApp Integration**: Direct one-click booking and dispatch notifications with pre-formatted vehicle telemetry.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS (Tailored dark mode, vibrant emergency gradients, glassmorphism)
- **Icons**: Lucide React
- **Mapping & Geo**: Leaflet / Custom Bhavnagar Geo Locality Engine

## 📦 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/mickrathod/motorescue-bhavnagar.git

# Navigate into the project directory
cd motorescue-bhavnagar

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
